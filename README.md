# HYPER WONDER

『スーパーマリオブラザーズ ワンダー』の遊び心を **オリジナルのドット絵・音楽・キャラクター** で再現した、ブラウザで遊べる 2D アクションゲームです。
依存ライブラリなし（HTML5 Canvas + 素の JavaScript）。push するだけで GitHub Actions が GitHub Pages に自動デプロイします。

> 任天堂の画像・音楽・名称は一切使用していないファンメイド作品です。

## 遊び方

| 操作 | キー |
|---|---|
| 移動 | ← → （A / D） |
| ジャンプ（長押しで高く） | Z / Space |
| ダッシュ・アタック（ゾウ形態のはな攻撃、あわ形態のあわ発射） | X / Shift |
| しゃがむ・すりぬけ床から降りる | ↓ |
| 決定 | Z / Enter / 画面タップ |
| ミュート | M |

スマートフォンでは画面上のボタンで操作できます。ブラウザの「ホーム画面に追加」を使うと、専用アイコンからフルスクリーンのアプリとして起動できます。

### 要素

- **ワンダーフラワー** … 触れるとコースが大変身。コースごとに違う「ワンダー効果」（ゆらゆら＋コインの雨、ふわふわ低重力、まっくら洞窟、のびちぢみする土管）が起き、**ワンダーシード**を取ると元に戻ります
- **パワーアップ** … グローベリー（大きくなる）、ゾウのフルーツ（はなでレンガや敵を吹き飛ばす）、あわのはな（あわで敵を包む。あわの上でジャンプもできる）
- **バッジ** … タイトル画面で1つ選ぶ。パラシュートぼうし／かべのぼり／ハイジャンプ
- **おしゃべりフラワー** … 近づくと話しかけてくる
- **フラワーコイン**（各コース3枚）と**ワンダーシード**の収集状況はブラウザに保存されます
- 全4コース、ゴールポールの高い位置をつかむほどボーナス

## 開発

```bash
npm test          # コースデータとスプライトの検証（Node 22 / 依存なし）
npm start         # http://localhost:8080/ で起動
npm run smoke     # Chromium を起動して実際に操作する動作確認（Playwright が入った環境向け）
npm run icons     # ホーム画面用アイコン（icons/）をドット絵から再生成
```

- `src/levels.js` … コースデータ。座標指定でタイルを置くビルダーで書かれており、`npm test` が整合性を検証します
- `src/game.js` … 物理・敵・アイテム・ワンダー効果・描画
- `src/sprites.js` … 文字列で定義したドット絵
- `src/audio.js` … WebAudio で合成する効果音と BGM

## 自動デプロイ（GitHub Actions → GitHub Pages）

`.github/workflows/deploy.yml` が次を行います。

1. どのブランチへの push でも `npm test` を実行
2. `main` への push なら、GitHub Pages を（未設定でも）自動で有効化し、`index.html` と `src/` をアーティファクトとしてアップロード
3. `actions/deploy-pages` で公開。公開 URL は Actions の実行結果（deploy ジョブの environment）に表示されます

手動で動かしたいときは Actions タブの「CI & Deploy to GitHub Pages」から **Run workflow** を押してください。
